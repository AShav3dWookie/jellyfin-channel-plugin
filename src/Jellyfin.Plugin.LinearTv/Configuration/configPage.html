Channels

Channels are built on another machine and copied into the store folder below (docs/architecture.md in the plugin's repository). Each loops on a fixed schedule and appears in Live TV; tuning in joins whatever is on, part-way through.

Settings

Where built channels are, as this server sees it: one folder per channel build.
Tuning in with less than this left of a programme starts the next one instead of catching the credits, putting you that far ahead of the guide. Zero (the default) always joins where the broadcast is, like real TV.

How far ahead the guide shows is Jellyfin's own setting: Dashboard → Live TV → guide data days (7 by default, 14 at most).
